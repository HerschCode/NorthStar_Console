ℹ What am I looking at? ▲

This dashboard shows live procurement process data for Northstar Manufacturing.

Cycle Time — how long it takes from purchase order creation to delivery. The 30-day reference line is an illustrative internal target, not a sourced industry benchmark. Northstar's average is highlighted.

SLA Breach Rate — the % of orders that exceeded their agreed delivery deadline. The 15% line is an illustrative target. Note: the configured SLA targets (10–14 days) sit far below this dataset's real cycle times, so ~94% of cases breach; see the project's evaluation docs.

Bottlenecks — which process stages cause the most delay, ranked by average hours spent there. The top stage explains most SLA breaches.

SLA Risk — each order is scored LOW / MEDIUM / HIGH by a calibrated Random Forest model trained on historical breach patterns. Its ROC-AUC shown below (~0.98) is on the configured 97%-breach target and is inflated; on realistic targets it is 0.84–0.88, and it is a late-stage score (most of its signal comes from features known late in a case). Risk score ≠ breach rate: the distribution shows predicted likelihood, not confirmed outcome.

Orders Needing Attention — the top HIGH-risk orders ranked by predicted breach probability. Each order shows SHAP feature attributions: signed, per-instance contributions from the model (positive = pushed breach probability up, negative = pushed it down), ranked by magnitude.

Supplier Performance — which suppliers are slowest and which breach SLA most often. Click any column header to re-sort. A worst badge marks the highest breach-rate supplier.

Recommended Actions — synthesised from the data above: the highest-impact interventions given current breach rate, top bottleneck, and worst-performing supplier.

Want to dig deeper? The Procurement Intelligence Agent can answer plain-English questions about this data — "Why did SLA breaches increase?" or "What does our rework policy say about supplier delays?" — and cites both the event-log evidence and the policy section it drew from.
